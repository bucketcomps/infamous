  • Saber ran our second batch of small graphics tests on his real PS3: 15 result files, nearly 15,000 measurements, all intact. Two tests were run twice and gave identical answers both times, so the console's behaviour is consistent.

Other PS3 games are starting to name parts of inFAMOUS

We dug through debug and prototype builds of several other PS3 games and demos. Some still carried their full lists of function names, and a few even carried their developers' own maps of the program.

  • We dug through debug and prototype builds of several other PS3 games and demos. Some still carried their full lists of function names, and a few even carried their developers' own maps of the program.
  • All of those names now sit in our private PS3 code library: several hundred thousand functions from many games, each labelled with where it came from and what kind of code it is.
  • Because many PS3 games share the same Sony and middleware code, we can recognise identical pieces of inFAMOUS this way. The first 25 inFAMOUS functions found like this passed an independent check. They include standard C library routines, Sony controller and file code, an MP3 decoder and video-playback code. They are being added to the project's name list now.
  • Along the way we fixed our own unpacking tool, which had been silently dropping exactly the name data we were looking for. An independent review caught it.
  • Every set of labels went through several rounds of independent review before it was accepted.

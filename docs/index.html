Screen-refresh stall fixed on the real game; the next stall is a timer; 4,059 proven

The refresh stall is fixed. The new hardware-timed clock had stopped at 231.3M instructions, waiting for a screen refresh that never came. The refresh deadline existed, but three idle things (a waiting trophy callback, a paused helper chip, and its timer) counted as "busy", so time never moved forward. Those exact idle states are now allowed to let time pass; anything ready to run still blocks. A second engine tried five ways to break it and found none.
